# 🍽️ BookingAI - Restaurant Booking SaaS

> **Piattaforma SaaS multi-tenant per gestione prenotazioni ristoranti con AI**

## 🚀 Features

- ✅ **Multi-Tenant Architecture** - Isolamento completo dati tra ristoranti
- ✅ **Dashboard Moderna** - UI sublime con shadcn/ui
- ✅ **Gestione Prenotazioni** - Sistema prenotazioni completo
- ✅ **Table Management** - Gestione tavoli in tempo reale
- ✅ **Waitlist System** - Lista d'attesa digitale
- ✅ **CRM Clienti** - Profili clienti e storico
- ✅ **Analytics** - Dashboard analytics avanzati
- ✅ **AI Optimization** - Ottimizzazione tavoli con AI

## 🛠️ Tech Stack

- **Next.js 15** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Drizzle ORM** - Database
- **PostgreSQL** - Database
- **shadcn/ui** - UI Components

## 🚀 Quick Start

```bash
# Install
bun install

# Setup database
bun run db:push

# Run dev server
bun run dev
```

## 📊 Database Schema

- **tenants** - Ristoranti
- **users** - Staff multi-ruolo
- **guests** - Clienti CRM
- **reservations** - Prenotazioni
- **tables** - Tavoli
